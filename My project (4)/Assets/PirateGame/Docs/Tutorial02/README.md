# 2차 튜토리얼 — 기능별 Game Feel 구현

## 제공 상태
8개 기능을 개별적으로 구현하는 튜토리얼입니다.
각 단원에 전체 코드 또는 정확한 수정 위치, 오브젝트 계층, 컴포넌트, Inspector 값, 참조 연결, 완료 기준을 제공합니다.
Scripts/Feel의 새 클래스 11개는 TODO 주석만 있는 빈 상태입니다.
기존 게임 스크립트·씬·프리팹에 2차 기능을 미리 적용하지 않았습니다.

먼저 [공통 준비](00_Setup.md)에서 실습용 씬과 프리팹을 복제하세요.
1차 설계·문서와 2차 문서는 별도로 유지합니다.

07의 기존 카메라 유지 부분 역시 선택입니다.

## 1차와의 차이
1차는 기본 게임 루프와 발사·명중·격침 사건의 Juice 연결을 학습합니다.
2차는 조작의 무게, 정보 전달, 적 공격 판단, 전투 종료와 성장의 감각을 학습합니다.
공용 코드 변경은 01 ShipMotor, 05 EnemyShipAI, 07 GameFlowController, 08 ResultPanel에서 명시합니다.
설정/새 컴포넌트가 없는 기본 씬은 기존 동작으로 남도록 구성합니다.

## 검증
제공한 전체 코드 예제는 단원별 조합과 통합 조합으로 컴파일을 확인합니다.
실제 구현 후에는 [단원별·통합 완료 체크리스트](09_Checklist.md)로 플레이를 확인하세요.
컴파일 확인이 연출 수치의 최종 확정이나 모든 기능의 플레이 검증을 뜻하지는 않습니다.

설계 배경과 책임은 [확장 설계](02_ExtensionDesign.md)를 확인하세요.
