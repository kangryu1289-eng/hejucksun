# 2차 실습 완료 체크리스트

## 1. 공통
- [ ] 기본 PirateBattle과 실습 PirateBattle_Feel이 별도 씬이다.
- [ ] 두 선박과 포탄은 실습 프리팹 복사본을 참조한다.
- [ ] UI는 TextMeshProUGUI/TMP_Text이고 빠진 참조가 없다.
- [ ] 두 번 이상 재출항해 이벤트나 효과가 중복되지 않는다.
- [ ] Console에 게임 코드 컴파일 오류·NullReferenceException이 없다.

## 2. 개별 확인
| 단원 | 필수 확인 | 끄고 비교할 대상 |
|---|---|---|
| 01 | 가속·제동·후진·속도별 선회, 섬·경계 충돌 | Handling=None, Damping 원복 |
| 02 | 실제 속도로 방출, 정지·후진·섬 접촉 | WaterWake |
| 03 | 궤적·그림자와 기존 충돌/데미지 | 표현 컴포넌트와 자식 |
| 04 | 발사당 완료음 1회, 초기 소리 없음, 강화 반영 | ReloadIndicator |
| 05 | 확정 목표점, 예고 중 이동·격침·전투 종료 취소 | EnemyAttackController |
| 06 | 50/25% 경계, 경고 중복 없음, 사망 후 정리 | ShipDamageVisual/선택 프로필 |
| 07 | 0.8초 뒤 결과, 중복 정산 없음, Director 중단 시 완료 | BattleEndingDirector |
| 08 | 표시 중 화면 이동, 레벨 한도, 실제 골드 일관성 | 새 표현 컴포넌트/텍스트 |

## 3. 통합 플레이
- [ ] 이동 중 발사·피격이 동시에 발생해도 Pivot의 위치가 누적되지 않는다.
- [ ] 적 예고 중 Hit Stop이 발생하면 예고 시간도 게임 시간에 맞춰 잠깐 멈춘다.
- [ ] 마지막 적 격침 후 추가 예고·발사·피해가 발생하지 않는다.
- [ ] 종료 연출 중 시간 배율이 정상 복구된다.
- [ ] 결과 보상 카운트업을 중간에 닫아도 실제 보상은 한 번만 지급된다.
- [ ] 패배 후 50 HP 복구와 다음 출항이 정상이다.
- [ ] 기본 씬은 관성/예고/종료 대기 설정 없이 기존 루프를 유지한다.

## 4. 확인 수준
문서 예제의 컴파일 확인과 학습자가 Inspector에 연결한 결과의 플레이 확인은 구분합니다.
기존 개발 검사 44개는 기본 루프 회귀 확인용입니다. 임의의 실습 씬 참조나 모든 연출 조합을 대신 검사하지 않습니다.
04 재장전과 06 경고에는 실제 청취 확인도 필요합니다.

Unity 6000.0.57f1의 에디터 폰트 assertion은 게임 코드 오류와 구분합니다.
로그가 IMGUI/TextCore 폰트 아틀라스 경로라면 엔진 이슈 UUM-85059를 확인하세요.
기존 [문제 해결 문서](../04_Verification.md)와 실제 전체 스택을 함께 확인합니다.
